Settings

This page is static — there is no server behind it. To actually run the compiler you either bring your own API key, or point it at a backend you control.

Read this before pasting a key. In Direct mode the key is stored in this browser's localStorage and sent from the page itself, so anyone who can open devtools on this device can read it. That is acceptable for a personal tool with your own key — it is not acceptable for a key with broad access, a shared machine, or a key you also use in production. Use a dedicated, rotatable key, or use Proxy mode. The key is never sent anywhere except api.anthropic.com.

POSTs {system, user, max_tokens, model} and reads back streamed text or {text}. A ready-to-deploy Cloudflare Worker is in proxy/worker.js in the repo.
